# Front-end Disparo

Projeto frontend para interface de rede e comandos do sistema.

## Descrição

Este é um projeto frontend desenvolvido em HTML, CSS e JavaScript que permite:
- Verificar status da conexão com API backend
- Executar comandos no servidor através da API
- Exibir informações do sistema e rede

## Tecnologias Utilizadas

- HTML5
- CSS3 com design responsivo
- JavaScript Vanilla
- Fetch API para comunicação com backend
